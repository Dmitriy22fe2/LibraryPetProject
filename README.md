# Library Management System

Веб-приложение на Spring MVC для учета читателей и книг в библиотеке.


## Технологический стек

- Java 25
- Spring Framework (MVC, ORM)
- Hibernate / JPA
- Gradle
- PostgreSQL
- Docker Compose
- SmartTomcat (для локального запуска)


## Конфигурация базы данных

Проект настроен на запуск "из коробки". Файл конфигурации `src/main/resources/hibernate.properties` уже содержит дефолтные параметры подключения к локальной базе данных в Docker и режим автоматической генерации таблиц (`hibernate.hbm2ddl.auto=update`).


## Инструкция по запуску

После открытия проекта в IDE убедитесь, что все зависимости синхронизировались правильно. Синхронизируте зависимости кнопкой Reload All Gradle Projects во вкладке Gradle. В случае проблем с локальным кешем среды разработки, выполните в терминале ./gradlew cleanIdea idea и повторите синхронизацию.

Разверните контейнер с PostgreSQL с помощью IDE или выполнив команду в терминале:
```bash
docker-compose up -d
```
База данных поднимется на порту 5491.


Запуск приложения в IDE. Поскольку проект построен на чистом Spring MVC (без Spring Boot), для запуска используется плагин SmartTomcat в IntelliJ IDEA:

1. Установите плагин SmartTomcat через настройки среды разработки.
2. Добавьте новую конфигурацию запуска (Run/Debug Configurations -> SmartTomcat).
3. В поле Tomcat Server укажите путь к папке со скачанным Apache Tomcat.
4. В поле Deployment directory выберите папку `src/main/webapp`. (важно: именно `webapp`, а не `web`)
5. В поле Context path оставьте только `/`.
6. Примените конфигурацию и запустите сервер Tomcat. Приложение будет доступно по адресу: http://localhost:8080/

## Навигация (Точки входа)

После запуска приложение доступно по адресу: http://localhost:8080/.
Основные разделы приложения:
- `/` Главная страница (содержит ссылки на ключевые разделы)
- `/people` Страница управления читателями. Функционал модуля: Просмотр списка читателей. Просмотр читателя и выданных ему книг. Добавление, редактирование и удаление читателей.
- `/books` Каталог книг. Функционал модуля: Просмотр списка книг. Просмотр книги. Добавление, редактирование, удаление, выдача и возврат книг.


## Особенности архитектуры 

- Автогенерация таблиц: Схема базы данных создается автоматически при первом запуске приложения благодаря Hibernate.
- Целостность данных: На уровне сущностей настроена связь ON DELETE SET NULL. При удалении читателя из базы, закрепленные за ним книги не удаляются, а автоматически становятся свободными.
